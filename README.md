# VSI

**Ready-made setup for Algorithm Design & Analysis projects. Your AI agent does the work.**
**Gati për projektet e Dizajnimit dhe Analizës së Algoritmeve. Agjenti yt AI e bën punën.**

---

## 🇦🇱 Si ta përdorësh

1. Lart në këtë faqe kliko **Code → Download ZIP** dhe hape ZIP-in.
2. Kopjo folderin **`vsi`** brenda projektit tënd.
3. Hape projektin në VS Code dhe shkruaji agjentit tënd (Copilot, Codex, Gemini, Claude, ChatGPT…):

> Lexo vsi/AGENTS.md dhe përgatit projektin tim: **[emri i projektit tënd]**

Kaq. Agjenti e gjen projektin, krijon skedarët, teston dhe të tregon hapin tjetër.

---

## 🇬🇧 How to use it

1. At the top of this page click **Code → Download ZIP** and unzip it.
2. Copy the **`vsi`** folder into your project.
3. Open your project in VS Code and tell your AI agent (Copilot, Codex, Gemini, Claude, ChatGPT…):

> Read vsi/AGENTS.md and set up my project: **[your project name]**

That's it. The agent finds your project, creates the files, runs the tests and tells you the next step.
